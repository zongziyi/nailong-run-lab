# 奶龙快跑 · 金币挑战与障碍跑酷 v0.4

一个使用原生 JavaScript + Three.js 的 3D 跑酷小游戏，手机和电脑都可以直接在浏览器中游玩。模型源自 **WeDai**，已在副本上调整体形、清理重复顶点、烘焙材质，并补充骨骼和四段动画。可旋转查看角色，也可进入三条铁路的随机障碍挑战。

## 在线游玩

**[点击这里，直接玩奶龙快跑](https://zongziyi.github.io/nailong-run-lab/)**

打开链接，选择“一条命”或“三条命”，点击“带奶龙跑一跑”即可。无需下载安装、登录账号或启动本机服务；第一次打开需要加载约 3.7 MB 的角色模型。

| 设备 | 操作 |
| --- | --- |
| 手机、平板 | 左右滑动换道，上滑跳跃，下滑滑铲；也可点击屏幕下方的方向按钮 |
| 电脑 | ← / → 或 A / D 换道，↑ / W / 空格跳跃，↓ / S 滑铲，Esc 暂停 |

滑铲时可以立即起跳；空中下滑或按下键可快速下铲，落地后接滑铲。切换到其他页面时会自动暂停。

点击开始后循环播放《地铁跑酷》经典主题曲，默认音量 35%。右上角的音符按钮可静音或恢复，选择会保存在当前浏览器；浏览器禁用存储时也可正常切换。暂停或进入后台时音乐暂停，继续时接着播放，重开从头播放，结算或返回角色观察时停止。音符按钮变为黄色表示播放受限或加载失败，可点击重试，游戏仍可继续。

音乐随网站从同一站点加载；曲目来源、原版权署名和文件校验信息见 [assets/audio/SOURCE.md](assets/audio/SOURCE.md)。

[查看角色造型对照](https://zongziyi.github.io/nailong-run-lab/comparison.html) · [复看动作衔接](https://zongziyi.github.io/nailong-run-lab/action-review.html)

## 本地开发与试玩（可选）

1. 双击项目目录中的 **启动试玩.cmd**，保持窗口打开；服务就绪后会自动打开浏览器。已有试玩服务时会直接打开它。
2. 若浏览器没有自动出现，手动打开 **http://127.0.0.1:4173/**。
3. 查看造型对照：**http://127.0.0.1:4173/comparison.html**。
4. 复看动作衔接：**http://127.0.0.1:4173/action-review.html**，支持正常速度、慢动作、暂停、逐帧前进及定位关键时刻。

本地开发需要 Node.js 24。下载或克隆仓库后运行 `npm ci`，再运行 `npm start`。Windows 也可双击 `启动试玩.cmd`，脚本会在缺少依赖时执行 `npm ci`。

**不要直接双击 `index.html`。** 地址栏若以 `file:///` 开头，浏览器会拦截游戏所需的模块。误开文件时页面会提示启动方式，并提供打开本机试玩的按钮；脚本异常或加载超时也会显示原因，不会一直显示“正在热身”。

本地开发服务只监听 `127.0.0.1`。在手机或其他电脑上游玩，请使用上面的在线链接，无需让开发电脑保持开机。

## 自动部署

在线版由 GitHub Pages 托管。推送到 `main` 后，GitHub Actions 会安装锁定依赖、运行测试与检查、执行 `npm run build`，再把 `dist/` 发布到同一个试玩链接。也可在仓库 Actions 页手动运行 **Deploy game to GitHub Pages**。

发布包包含页面、角色模型、造型对照素材和同站点托管的 Three.js 依赖；不上传 `node_modules`、Blender 源文件、开发工具或测试到网站。所有资源使用相对路径，适配 GitHub Pages 的项目子目录。生成的 `dist/` 不提交到 Git。

## 操作

- 查看角色：鼠标拖动 / 单指拖动旋转，滚轮 / 双指缩放；正面、侧面、背面按钮切换角度。
- 开始试玩：先选择“三条命 / 一条命”，再点击“带奶龙跑一跑”。默认三条命；重开或返回查看角色时保留选择，刷新页面恢复三条命，游戏中不能切换。
- 换道：← / → 或 A / D；触屏左右滑动。
- 跳跃：↑ / W / 空格；触屏上滑。滑铲进入、保持或恢复阶段均可立即起跳。
- 滑铲：↓ / S；触屏下滑。空中使用会收腿快速下落，落地后接完整的 0.85 秒滑铲，期间仍可随时起跳。
- 暂停：右上角按钮或 Esc。页面失去焦点、进入后台时自动暂停。
- 暂停面板可继续、重置或返回查看角色。空中可换道；腾空期间不能再次起跳，重复下铲不重置动作；不缓存提前输入。
- 本局生命耗尽后，可点击“再跑一次”或按 Enter 沿用当前生命模式重开，也可返回“查看角色”切换模式。

## 障碍挑战

开局保留 3 秒缓冲，之后直接随机。初始速度仍为 8.8 游戏单位/秒，按 `8.8 + 4.5 × ln(1 + t / 15)` 持续加速，加速幅度比 v0.3 提高 50%；前期增长快、后期增幅减小，不封顶。约 30 秒为 13.7，2 分钟为 18.7，5 分钟为 22.5。`t` 只计实际游玩时间，距离按该曲线积分计算。

普通障碍组间隔缩至 1.6–2.1 秒，每次抽取有 70% 概率尝试双障碍，每组最多占两条跑道。长火车旁的其他跑道可以继续出现障碍；同一跑道在前一个障碍完全通过后至少留出 0.9 秒。不可放置的类型按剩余权重重新抽取，路线不安全则重抽，最多 8 次，再尝试安全的单路障或跳过。通过筛选后的实际双障碍比例会低于 70%。

路线按 0.1 秒时间网格检查，从起始中道保留连续可达的地面通路。相邻换道预留 0.4 秒，按控制器实际横向曲线检查全过程，并增加 0.05 单位余量；不依赖跳跃、滑铲或上车顶才能通关。为验证完整金币路线，目标维持前方至少 90 单位或未来 8 秒路程，使用 32 个池槽位，车顶障碍也计入总量。

| 障碍 | 通过方式 | 尺寸（游戏单位） |
| --- | --- | --- |
| 橙白矮路障 | 跳跃或换道，脚部需升至 0.70 以上 | 宽 1.8、高 0.65、深 0.8 |
| 红白吊挂横杆 | 滑铲或换道，滑铲开始后 0.20–0.65 秒有效 | 宽 1.8、下缘 1.65、厚 0.35、深 0.45 |
| 棕色堆叠货箱 | 跳跃或换道，脚部需升至 1.10 以上；箱顶不能落脚 | 宽 1.6、高 1.05、深 1.2 |
| 轨道内停靠火车 | 沿斜坡自动上车顶，或换道；无坡车正面与车身侧面会撞击 | 宽 1.8、高 3.8、车身长 18；斜坡长 8 |
| 红色迎面列车 | 提前换道；无坡道，车顶不能落脚 | 宽 1.8、高 3.8、长 18；迎面速度 6 单位/秒 |

普通障碍抽取权重为矮路障 / 横杆 / 货箱 / 停靠火车 / 迎面列车 = 25 / 25 / 25 / 15 / 10。迎面列车每组最多一辆，两次到达至少间隔 6 秒；接近前 2.4 秒显示所在跑道提示和地面红色箭头。暂停时列车与警示一起冻结。

第一辆随机出现的火车带坡，后续火车有 50% 概率带坡。车顶可以跑、跳、滑铲和换道；跑过车尾或离开边缘后自然下落，下降时可以落到另一车顶。当前没有专门安排连续跨车挑战。命中的火车淡出后也会失去支撑。

70% 的停靠火车尝试放置 1–2 个车顶路障或横杆。首个距车头至少 `max(4, 到达速度 × 0.35)`，车尾留出至少 2 单位，车顶障碍前缘间隔至少 1.05 秒；放不下时减少数量。它们的高度相对车顶计算，地面通过时不会撞到；父列车被消耗时，附属障碍一起淡出并撤销碰撞。

正常登坡后可在坡道任意位置起跳：跳跃按当前位置坡面/车顶高度衔接，保持原有高度与时长。离开该列车后转为自由下落；从上方跨到另一辆停靠火车的坡面或车顶时正常落地，前后错开的坡顶交界也不会误伤。从下方撞入车身、撞到车顶障碍或红色迎面列车仍会扣命。

试玩角色已缩至 80%，观察模式仍保持原展示大小。镜头保持原来的距离并跟随坡道、车顶及腾空高度。滑铲改为身体后仰、前伸一腿、另一腿弯曲的动作，总长 0.85 秒；稳定窗口碰撞高 1.35、深 1.25，站立碰撞高 2.36、宽深均 0.64。碰撞体刻意比完整角色轮廓宽松。

动作可连续衔接“滑铲 → 起跳 → 空中下铲 → 落地滑铲 → 再起跳”。滑铲起跳立即退出低姿态碰撞窗口，跳跃高度与时长保持不变。空中下铲从当前高度开始，向下初速度至少 12、重力为正常值的两倍，落地前仍使用站立碰撞体；按实际落地时刻切分物理步，再开始完整的 0.85 秒滑铲。落地滑铲在 0.10–0.65 秒间使用低碰撞体，普通地面滑铲仍为 0.20–0.65 秒。

骨骼及根节点从当前显示姿势用 0.10 秒平滑接入下个动作，快速连续操作也从当前混合姿势继续。下铲使用跳跃中段的收腿姿势，落地直接接滑铲保持姿势；奔跑相位跟随累计路程。接触点对视觉贴地进行小幅修正，不改变角色物理高度或碰撞体。原始模型及四段内置动作未修改。

每局可选三条命或一条命。撞击扣一命，尚有生命时获得 1.5 秒保护；命中障碍淡出，同一障碍只触发一次。保护期间接触的障碍也会被消耗，不会在保护结束后补扣。两旁装饰火车不参与碰撞。

顶部按所选模式显示生命数量，同时显示距离、速度倍率和保护倒计时，来车时额外提示危险跑道。暂停冻结动作、障碍、警示、距离、速度和保护计时；重开会清空命中、支撑、垂直运动、来车冷却及动作状态。一条命模式第一次有效撞击立即结算，三条命模式第三次有效撞击结算，停止移动与里程更新。

## 金币挑战

每枚金币计为 1，只统计本局。HUD 同时显示生命、金币、速度和距离；结束面板显示本局金币，重开或返回观察时清零。本次不增加累计钱包、商店、道具或完整地图。

金币集中在障碍挑战位置：路障和货箱上方的跳跃弧线、横杆下的滑铲路线、可登上的坡道与车顶。当前所有金币都属于障碍挑战串，空跑道不铺长串金币。金币不会放进障碍实体、迎面列车内部或无法到达的车顶；火车失去支撑后，其附属金币同步撤销。

保留开局 3 秒热身。前 20 秒以单次动作为主，20–60 秒尝试加入连续动作和左右分支，60 秒后提高组合与分支的尝试比例。分支任选一边，不要求同时收集两边；选中的路线经过障碍后衔接后续路线。

金币规划复用控制器实际物理与碰撞，在独立副本中验证每条分支以及汇合后的衔接。无伤路线验证通过才显示金币，后续障碍不能破坏已显示的路线；视野不足或路线无法衔接时等待更多障碍信息，必要时舍弃尚未显示的挑战段，保留原地面通路。实际分支与组合数量受可达性筛选影响，部分障碍没有金币。

金币使用 384 个固定数据槽位与共享实例网格，缓慢旋转和浮动；吃到后闪光并消失。拾取检测覆盖实际横向位置、高度和帧内移动过程，每枚只奖励一次，最终撞击之后不计数。暂停冻结金币、闪光及计数。

右上角 ◉ 按钮独立控制金币音效，♫ 按钮只控制背景音乐。吃金币播放 Web Audio 合成的双音叮声，无需下载额外音频；开始、继续或操作时启用音频，暂停、静音、结算和返回观察会清除尚未结束的声音。音效静音选择独立保存在当前浏览器，存储或音频不可用时仍可游玩。

本次自动测试和桌面 / 手机尺寸浏览器检查见 [artifacts/VALIDATION-coins.md](artifacts/VALIDATION-coins.md)。

## 模型制作与检查

本项目内的 `.tools/blender-5.2.2-windows-x64/blender.exe` 是从 Blender 官方下载站取得的便携版，未安装到系统。

```powershell
& '.\.tools\blender-5.2.2-windows-x64\blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/prepare_model.py
& '.\.tools\blender-5.2.2-windows-x64\blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/render_model.py
& '.\.tools\blender-5.2.2-windows-x64\blender.exe' --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/render_slide_review.py
npm run check
npm test
```

重建模型会覆盖修改后的模型、贴图、检查报告；不会覆盖 `assets/source` 内的原模型。

仅更新滑铲可运行 `tools/update_slide.py`，它读取现有修改版 `.blend` 并替换 `Slide`，不会重烘焙材质。姿势定义位于 `tools/slide_pose.py`，完整模型生成也使用同一份定义。

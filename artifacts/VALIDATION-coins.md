# 金币挑战验证记录

日期：2026-10-18。本文件记录金币功能的本地验证；线上发布状态以 GitHub Pages 部署记录为准。

## 功能

- 每枚金币 +1，本局计数、结算和重开清零；不保存累计钱包。
- 金币围绕路障、货箱、横杆、坡道和可达车顶生成；当前金币全部属于障碍挑战串。
- 按实际物理模拟验证连续路线及分支，携带两条分支的汇合状态继续验证下一段。后续障碍候选不得破坏已显示的挑战路线。
- 前 20 秒以单次动作为主，20 秒后尝试动作组合及分支，60 秒后提高尝试比例。速度曲线不变，生成视野目标扩大到未来 8 秒，供完整挑战段验证。
- 384 个固定金币记录和实例容量，共享几何体及材质；拾取后闪光，火车被消耗时撤销失去支撑的金币。
- 独立金币音效开关及静音存储。Web Audio 合成双音，无额外音频资源；停止状态清除正在播放和排队的声音。

## 自动检查

`npm test`：104 项通过，0 失败（原有 89 项加 15 项金币相关测试）。新增动作组合断言单独复跑通过。

- 1,000 个随机种子、各 20 秒的金币路线回放：5,962 段挑战、33,401 枚金币；选中路线的金币均能收集、没有扣命、没有嵌入障碍实体，障碍关联占比 100%。
- 原有 1,000 条地面安全路线测试通过，仍可只依赖换道通关。原有障碍权重、保护期、地形及动作衔接测试通过。
- 30 / 60 / 120 FPS、包含 0.25 秒掉帧，分别选择分支两边并继续后续路线；总计回放 6 次分叉，全部通过，后期均出现动作组合。
- 随机种子 17 连续跑 240 秒，包含选择另一条分支和掉帧，检验后期速度、金币收集及历史记录有界。
- 拾取检测覆盖横向实际位置、跳跃高度、滑铲、车顶、高速跨越、只奖励一次、最终碰撞前后的计数、暂停与重开。
- 数据池及实例几何体经过 1,000 次回收复用；音效测试覆盖独立静音、存储失败、音频不可用、延迟启用、取消声音及连续拾取声部上限。

`npm run check`：通过。37 个控件、模块与资源检查通过；63 个角色位置和 2,106 个障碍投影几何检查通过。

`npm run build`、`git diff --check`：通过。静态构建包含新增模块；原有发布构建测试验证相对路径、完整模块依赖以及 Three.js 本地资源。

## 实际浏览器检查

使用运行环境自带 Playwright、已安装的 Chrome 和软件 WebGL，访问本机 HTTP 服务。浏览器控制接口初始化失败后采用该方式，不额外安装依赖。临时验收脚本在 `.cache/qa-coins.cjs`。

- 桌面 1280×900：通过界面操作启动一条命模式，并通过键盘事件跟随只读快照中的路线。实际收集 5 枚金币，计数与结算一致，重开清零。
- Web Audio 实际合成并播放 5 次金币声音。旁路分析器检测到约 0.0519 的非零最大 RMS；这是自动化音频波形验证，并非人工听感评价。
- 暂停后距离和金币数量保持不变，待播放声音已清除；继续可恢复，音乐静音和金币音效静音彼此独立。
- 390×844 和 320×640 手机尺寸：生命、金币、速度、距离、音乐、音效和暂停控件均在视口内；金币可见，页面运行未出现 JavaScript 错误。
- 尚未验证手机真机、设备扬声器听感或实际设备帧率。

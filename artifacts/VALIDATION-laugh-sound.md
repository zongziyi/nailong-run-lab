# 捧腹大笑短音效

2026-10-19，本地修改及验证，未发布。

## 素材

- 使用已有 Blender `aud` 解码用户指定视频，未安装 FFmpeg，原视频未修改或复制进项目。
- 截取 0.55–1.60 秒，输出 `assets/audio/nailong-laugh.wav`，1.05 秒、单声道、44,100 Hz、16 位 PCM、92,654 字节。
- 淡入 10 ms、淡出 60 ms；量化后峰值 −3.0001 dBFS，削波样本数 0，首尾样本均为 0。
- 使用同一输入重新生成至 `.cache`，两次 WAV 摘要一致。参数和源文件/输出摘要见 `laugh-audio-report.json` 及音频来源说明。
- 本轮未直接听辨音色，交付 WAV 供试听；内容选择来自用户指定视频及约定截取区间。

## 接入

- 保留 CoinSound 及控制器原有接口；新增 `playLaugh(game)`，仅由已接受的下滑手势调用，并检查地面 Slide、`slideFromDive=false` 及动作序号。
- 单个预加载的媒体元素避免声音叠加，音量 60%；已开始的短笑可跨越动作结束或起跳自然收尾。
- 未开始且已过时的异步请求取消；暂停、后台、重开、退出、游戏结束及静音均清理播放，恢复/重试不补播。
- 原静音键继续保存设置，界面改称“游戏音效”，金币声与笑声共用，背景音乐保持独立。
- 动画复看页保持静音；构建自动包含 WAV 和来源记录，不含原 MP4。

## 验证

- 21 项音效/音乐专项测试通过，含真实控制器动作链、屋顶、重复输入、原滑铲、静音持久化、延迟请求、加载失败及自动播放拒绝。
- 完整测试：155 / 155 通过；`npm run check` 通过。
- 静态构建测试核对 WAV 完整复制、项目子路径引用及原 MP4 未打包。
- 桌面浏览器首次地面大笑：显示“捧腹大笑！”，WAV 预载状态 4、时长 1.05 秒、无媒体错误，播放计时正常推进；背景音乐同时播放。
- 暂停：笑声与背景音乐均暂停，笑声计时归零。关闭游戏音效：笑声静音且不播放，背景音乐继续。
- 跳跃后下滑落地：原滑铲仍正常，笑声处于暂停且计时为 0。
- 390 × 844 浏览器：大笑时笑声与音乐均播放，页面无横向溢出，随后暂停清理；已恢复临时视口设置。

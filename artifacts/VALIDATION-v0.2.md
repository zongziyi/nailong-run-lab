# 随机障碍与三条命 · v0.2 验证记录

日期：2026-10-17。范围：本机试玩，没有注册站点或发布上线。角色模型与原作者 WeDai 的署名、来源链接继续保留。

## 已实现

- 3 秒缓冲后遭遇随机障碍；每组 1–2 个不同跑道的障碍，至少一条空道，前缘间距 24–30。速度固定 8.8，跑道间距 2.15。
- 橙白矮路障、红白吊挂横杆、带车窗与警示灯的轨道内火车。两旁装饰火车继续保留，不参与碰撞。
- 配置集中在 `src/game-config.js`。障碍位置以绝对前缘里程及长度计算，网格与判定使用同一配置；测试核对实际实体网格边界。
- `src/obstacles.js` 为独立纯 JavaScript 模块，可注入随机数源。碰撞扫掠上一帧到当前帧的实际横向位置、高度和距离，不依据目标跑道瞬间避让。
- 每局三条命，撞击后保护 1.5 秒；保护内的接触也消耗该障碍，避免随后补扣。命中障碍淡出，反馈包含身体轻晃、文字与护罩提示。
- 三次有效撞击后冻结里程、移动和角色动作，显示距离；支持按钮或 Enter 重开，以及返回查看角色。暂停冻结保护与动作计时，重开清空路线、命中、动作状态并重新开始动画播放。
- 数据池与渲染池各 16 个槽位，维持前方约 90 单位路线。渲染槽位预建三个障碍变体，运行中复用几何体和材质。已经完全通过的障碍及时隐藏，避免长火车遮挡后方镜头。

以下均尚未验证：**实际浏览器交互、动作切换与重开动画的视觉效果、结算按钮与 Enter 的浏览器操作、手机尺寸的浏览器模拟、手机真机触控、实际帧率和最终网页截图**。逻辑测试、HTTP 检查、几何投影和 Blender 渲染不等同于这些检查。

页面已实现键盘、滑动和触屏按钮；服务只监听 `127.0.0.1`，另一台手机不能直接访问。后续实际体验时重点检查下滑时机、换道手感及画面遮挡。
